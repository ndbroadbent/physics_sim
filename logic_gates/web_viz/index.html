Visualizing a Computer with Only One Gate

It might seem counter-intuitive, but it's possible to build an entire computer using only one type of logic gate: the NAND gate. NAND is "functionally complete," meaning any other logic function (AND, OR, NOT, XOR, etc.) can be constructed from combinations of NAND gates.

To demonstrate this, the interactive component below simulates an 8-bit ripple-carry adder built entirely from NAND gates. You can input two numbers (from 0-255), and watch the binary signals propagate through the circuit in real-time to produce the sum.

Notice how the individual NAND gates are grouped into familiar components like AND, XOR, and Half Adders. The carry-out from one bit "ripples" to the next, which is characteristic of this simple adder design.
